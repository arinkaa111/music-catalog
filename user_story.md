# User Story — Music Catalog

**Автор:** Арина

## Роли

### 1. Гость
- Просматривает каталог треков
- Ищет треки по названию, жанру, исполнителю
- Просматривает карточку трека

### 2. Пользователь (авторизованный)
- Всё, что может гость
- Добавляет треки в «Избранное»
- Ставит лайки
- Оставляет комментарии
- Создаёт плейлисты

### 3. Администратор
- Всё, что может пользователь
- Добавляет новые треки
- Редактирует карточки треков, альбомов, исполнителей
- Удаляет треки и комментарии
- Управляет пользователями через админ-панель

## User Stories

- Как гость, я хочу искать треки по названию, чтобы быстро находить нужную музыку.
- Как гость, я хочу фильтровать треки по жанру, чтобы находить музыку по настроению.
- Как пользователь, я хочу добавлять треки в «Избранное», чтобы возвращаться к любимой музыке.
- Как пользователь, я хочу оставлять комментарии, чтобы делиться мнением.
- Как администратор, я хочу добавлять новые треки, чтобы каталог пополнялся.
- Как администратор, я хочу редактировать карточки, чтобы исправлять ошибки.

## Модели данных

- **Artist** (id, name, country, description)
- **Album** (id, title, year, artist_id → Artist)
- **Track** (id, title, genre, duration, album_id → Album)
- **User** (id, username, email, hashed_password, role)
- **Favorite** (id, user_id → User, track_id → Track)
- **Comment** (id, text, created_at, user_id → User, track_id → Track)

Связи:
- Artist 1—N Album
- Album 1—N Track
- User N—N Track (через Favorite)
- User 1—N Comment
